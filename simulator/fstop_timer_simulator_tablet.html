Proposed knob behaviour

  • Turn: change the selected value by one step size per click.
  • Press: choose what the knob changes: stops, base time, then step size.
  • Touch: the Start / Pause / Resume button at the bottom.
  • Drag the ring, use the mouse wheel, or the left and right arrow keys to turn it.
  • While an exposure runs, the display shows the countdown and a progress ring, and turning is ignored.

    Messages between the units

    Status updates arrive about ten times a second and are not listed.

      Things to try
      1. On the Time tab, press a start-time preset, change the step size, then press Start. Set the speed to 5× to watch a long exposure quickly.
      2. On Strip test, run the test and watch the enlarger switch off between steps while the next strip to cover is shown. Tap a strip afterwards and choose Use selected strip.
      3. On Recipe, add a burn and a dodge and run it. Dodge hold times count down during the main exposure.
      4. Start an exposure and switch the Bluetooth link off. The relay finishes the exposure and the screen catches up when the link returns.
      5. Switch focus light on, then cut the link. The relay switches the enlarger off after the heartbeat is lost.
      6. Use the foot pedal with the screen on a different tab. It still starts the last armed exposure.
      7. Open the round knob view and turn the knob. Press it to change what it adjusts.
      8. In Tablet setup, switch off the red film, fullscreen or Do Not Disturb and see what the screen would look like. Send a test notification with Do Not Disturb off.
      9. Cut the Bluetooth link and restore it. With Web app you must tap Reconnect and use the bright pairing dialog; with Wrapped app it reconnects by itself.
      10. Lower the brightness in focus mode with the red film off. With Wrapped app the glow dims; with Web app it does not.
